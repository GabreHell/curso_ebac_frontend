# Curso EBAC — exercício de Git

## Como consultar

Leia o arquivo diretamente no GitHub ou clone o repositório:

```sh
git clone --branch exercicio_git https://github.com/GabreHell/curso_ebac_frontend.git
cd curso_ebac_frontend
```

Abra o arquivo de texto em qualquer editor. Esta branch não contém uma aplicação executável, dependências ou etapa de compilação.
